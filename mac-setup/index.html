Set up Wrapped on Mac.

About five minutes. Full Disk Access is required because macOS protects the Messages library.

1. Install the companion

  1. Download Wrapped for Mac.
  2. Open the downloaded ZIP.
  3. Move Wrapped Mac to your Applications folder.
  4. Open Wrapped Mac from Applications.

The download is signed with an Apple Developer ID and notarized by Apple. You do not need Xcode or a developer account.

2. Grant Full Disk Access

  1. In Wrapped Mac, select Open Full Disk Access.
  2. Unlock the macOS setting if requested.
  3. Turn on access for Wrapped Mac. If it is not listed, select + and choose it from Applications.
  4. Quit and reopen Wrapped Mac if macOS asks you to.
  5. Return to Wrapped Mac and select I turned it on — check again.

Wrapped opens the locally synced Messages database read-only. It cannot send, edit, or delete messages.

3. Pair your iPhone

  1. Put the Mac and iPhone on the same Wi-Fi network.
  2. Keep Wrapped Mac open so its 12-character code is visible.
  3. On the iPhone, open Wrapped and choose Connect your computer.
  4. Allow Local Network access if iOS asks.
  5. Select your Mac, enter the code, and choose Pair securely.

4. Choose conversations

After pairing, choose conversations on the iPhone. Only the conversations you select stream directly between the two devices through an encrypted session. The Mac companion does not create an export file.

If the Mac does not appear

  • Confirm both devices are on the same Wi-Fi network.
  • Keep both Wrapped apps open.
  • Check that Local Network access is enabled for Wrapped on the iPhone.
  • Turn off a VPN temporarily if it blocks local-device discovery.
  • Generate a new code in Wrapped Mac and try again.

Contact Wrapped support without including private messages, access tokens, or payment information.
