Set up ChatRecap on Mac.

About five minutes. Full Disk Access is required because macOS protects the Messages library.

1. Install the companion

The current signed download may still appear as Wrapped Mac in Applications and Full Disk Access. It is the same ChatRecap companion; use that name when following the steps below.

  1. Download ChatRecap for Mac.
  2. Open the downloaded ZIP.
  3. Move ChatRecap Mac to your Applications folder.
  4. Open ChatRecap Mac from Applications.

The download is signed with an Apple Developer ID and notarized by Apple. You do not need Xcode or a developer account.

2. Grant Full Disk Access

  1. In ChatRecap Mac, select Open Full Disk Access.
  2. Unlock the macOS setting if requested.
  3. Turn on access for ChatRecap Mac. If it is not listed, select + and choose it from Applications.
  4. Quit and reopen ChatRecap Mac if macOS asks you to.
  5. Return to ChatRecap Mac and select I turned it on — check again.

ChatRecap opens the locally synced Messages database read-only. It cannot send, edit, or delete messages.

3. Pair your iPhone

  1. Put the Mac and iPhone on the same Wi-Fi network.
  2. Keep ChatRecap Mac open so its 12-character code is visible.
  3. On the iPhone, open ChatRecap and choose Connect your computer.
  4. Allow Local Network access if iOS asks.
  5. Select your Mac, enter the code, and choose Pair securely.

4. Choose conversations

After pairing, choose conversations on the iPhone. Only the conversations you select stream directly between the two devices through an encrypted session. The Mac companion does not create an export file.

If the Mac does not appear

  • Confirm both devices are on the same Wi-Fi network.
  • Keep both ChatRecap apps open.
  • Check that Local Network access is enabled for ChatRecap on the iPhone.
  • Turn off a VPN temporarily if it blocks local-device discovery.
  • Generate a new code in ChatRecap Mac and try again.

Contact ChatRecap support without including private messages, access tokens, or payment information.
