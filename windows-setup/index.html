Set up Wrapped on Windows.

About five minutes after your iPhone has a local backup.

1. Back up your iPhone

  1. Install or open Apple Devices on your Windows PC.
  2. Connect your iPhone with a cable and approve Trust This Computer if asked.
  3. In Apple Devices, select your iPhone and choose Back up all of the data on your iPhone to this computer.
  4. Select Back Up Now and wait for it to finish.

If you encrypt the backup, remember the password. Wrapped can open an encrypted backup only after you enter that password locally.

2. Open the Windows companion

  1. Download Wrapped for Windows.
  2. Open Wrapped-for-Windows.exe. It runs directly; there is no installer wizard.
  3. If Microsoft Defender SmartScreen appears, select More info, verify that the app is from this official download page, then select Run anyway.
  4. Choose your newest backup. Enter its backup password if the app requests it.

This beta is not code-signed yet. Its SHA-256 checksum is a31272fec09f977053faaa71888fa0b57c6df7edcd7a94715d522ba9b93153e8.

3. Choose conversations

  1. Select the conversations you want to use.
  2. Start the secure connection and keep the companion open.
  3. Leave the 12-character pairing code visible.

Wrapped reads the backup locally and sends only the conversations you select through an encrypted connection on your local network.

4. Pair your iPhone

  1. Put the Windows PC and iPhone on the same Wi-Fi network.
  2. On the iPhone, open Wrapped and choose Connect your computer.
  3. Allow Local Network access if iOS asks.
  4. Select your PC, enter the code, and choose Pair securely.

If messages are missing

Apple can omit Messages from a computer backup when Messages in iCloud is enabled. If the companion reports this, review Apple’s Messages in iCloud guidance, then create a new local backup after the messages are stored on the iPhone.

If your PC does not appear

  • Confirm both devices are on the same Wi-Fi network.
  • Keep both Wrapped apps open.
  • Check that Local Network access is enabled for Wrapped on the iPhone.
  • Allow Wrapped through Windows Firewall if Windows asks.
  • Turn off a VPN temporarily if it blocks local-device discovery.

Contact Wrapped support without including private messages, backup passwords, access tokens, or payment information.
