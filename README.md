# Wrapped downloads

Public, static distribution site for Wrapped. The application source remains in a separate private repository.

- Website: https://hochpants.github.io/wrapped-downloads/
- Mac setup: https://hochpants.github.io/wrapped-downloads/mac-setup/
- Privacy: https://hochpants.github.io/wrapped-downloads/privacy/
- Android privacy: https://hochpants.github.io/wrapped-downloads/android-privacy/

`downloads/Receipts-for-Mac.zip` is replaced automatically after a Mac build is signed, accepted by Apple's notarization service, and stapled by the private build workflow.
