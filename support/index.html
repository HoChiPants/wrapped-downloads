Wrapped support.

Help with importing conversations, pairing a computer, and restoring Unlimited.

Contact support

Email the device you are using, the version of Wrapped, the step that failed, and any error message you saw. Do not include private messages, access tokens, backup passwords, or payment information.

Email Wrapped support Report a public bug

Try Wrapped with sample data

The sample is a fictional conversation created only for testing. It contains no real people or private messages.

  1. Download the sample conversation.
  2. If Safari previews the file, use Share and choose Save to Files.
  3. Open Wrapped and choose WhatsApp, GroupMe, or file export.
  4. Choose Choose export from Files, then select wrapped-review-sample.csv.
  5. Tap App Review Demo. The free review uses the latest 12 months.

Computer pairing

  • Keep the iPhone and computer on the same Wi-Fi network.
  • Keep both Wrapped apps open during pairing.
  • Allow Local Network access for Wrapped on the iPhone.
  • Temporarily disable a VPN if it blocks local-device discovery.

Read the Mac setup guide or read the Windows setup guide.

Restore Wrapped Unlimited

Open the Unlimited screen in Wrapped and choose Restore purchase. Use the same Apple Account or Google Account that made the original purchase. If no purchase is found, confirm that the store account is correct and try again.

Privacy

Wrapped analyzes selected conversations on your device. Support never needs a copy of your private messages. Read the iPhone privacy policy or Android privacy policy.

Never post message exports, passwords, access tokens, pairing codes, or payment details in a public GitHub issue.
