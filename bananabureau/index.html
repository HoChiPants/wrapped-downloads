◒ BANANA BUREAU

Select. Scan. Crop. Share.

Banana Bureau measures bananas and other small objects using on-device images and LiDAR. There is one scanning flow.

  1. Select: open 3D Object Scan, frame the whole object or draw a tighter box, then tap Select & scan. Capture starts automatically.
  2. Scan: turn slowly with overlapping detail, change grip to reveal the underside and tilt toward both tips. Flashlight is available where supported. Move back if focus struggles. The camera preview has fixed framing with no automatic crop or zoom.
  3. Inspect: Angle guide offers optional prompts; Highlight shows the current detected foreground. Both can be switched off. Prompts are not completed-surface checks. Aligned viewpoint coverage is shown in review.
  4. Crop: open Edit / rotate. One finger draws a Crop points box, two fingers rotate and pinch zooms. Cut removes orange selected points through the cloud's depth; Undo restores an edit. Accept saves the geometry.
  5. Fix a view: while the capture is open, Captured views lets you crop an input or remove a bad view. Measured regions are linked to the 3D cloud and other contributing image masks. Image-only pixels have no corresponding depth. Undo restores edits; Cancel discards them. Removing a view re-fuses retained depth using existing alignment; it does not rerun photo pose estimation.
  6. File or share: check captured points and estimates, then generated name, country/region and optional public postal code. Consent publishes valid geometry immediately. Save & close keeps a private draft; resume or discard it on the main screen. Published records can share a point-cloud stats card, caption and public verification link/QR code. The filing alias credits the record, not independently verified physical ownership.

How many views?

The current conservative starting threshold is twenty saved images including eight depth-bearing views, up to 120 inputs. Counts do not prove coverage. Continue capturing missing angles when review is partial. Smooth, reflective or blurred surfaces may fail alignment. Trimming cannot repair warped registration or generate missing surfaces.

Private inputs, public geometry

Masked images, depth and calibration remain protected and excluded from backups while the capture is active, including Scan more and local input editing. Accepting, closing or restarting deletes inputs; abandoned sessions are cleaned on app launch. Private drafts keep geometry, not input images. Nothing is saved to Photos. No captured photo or camera pose uploads. Local scan history retains up to thirty summary-only runs and can be cleared.

Current geometry checks support small three-dimensional objects about 5–60 cm long and 0.8–20 cm wide. Length/width are estimates; volume and girth use rounded-section/taper models. Complete reconstruction, solid volume and quarter-inch accuracy are not certified. Inspect the result before publishing.

Names are generated and location is self-selected worldwide. Postal code is optional and public. Reports can hide misleading records; no human photo review is involved. Delete records/account in the app. Contact bananabureau@studiominden.org. This static site has no cookies, analytics or trackers.
